# Plan: Data Analyst Course — Version 1 (Excel lesson + file checker)

## Context
You want a web app that teaches data analysis, starting with Excel. V1 is deliberately small:
1. One lesson page (explanation + downloadable practice `.xlsx` with a task)
2. An upload page for your completed file
3. A code checker that verifies answers **and** that you used formulas, not typed numbers

An AI tutor comes later (v2), so the checker should produce clean, structured results that an AI can explain later.

The project folder `data-analyst-course` is empty. Neither Python nor Node.js is installed on this PC — this matters for the tech choice.

## Technology: plain HTML + CSS + JavaScript, running entirely in the browser
- **No server, no install, no build step.** You double-click `index.html` and it opens in your browser. Nothing to learn except the three basic web languages.
- **SheetJS** (`xlsx.full.min.js`, one file saved into the project) reads and writes `.xlsx` in the browser. Crucially, it gives both a cell's **value** (`cell.v`) and its **formula** (`cell.f`) — exactly what the checker needs.
- Your uploaded file never leaves your computer; the checker runs in the browser.
- **Why not Python/Flask?** It would need Python installed, a server running in a terminal, and more moving parts. For v2 (AI tutor) we'll need a tiny server to keep an API key secret — we'll add it then. The checker written now can stay as-is and simply send its results to that server.

## The lesson (assumed — easy to change)
**"Your first formulas: SUM, AVERAGE, MIN, MAX, COUNT"** — the foundation of all Excel analysis.

Practice workbook, sheet `Sales`:
- `A1:D11` — data: Product, Region, Units Sold, Unit Price (10 rows, fixed numbers)
- Task 1: column `E` "Revenue" → `=C2*D2` … for rows 2–11
- Task 2: answer cells `H2:H6` with labels in `G2:G6`:
  Total revenue (SUM), Average units (AVERAGE), Highest price (MAX), Lowest units (MIN), Number of sales (COUNT)

The practice file is **generated by the lesson page when you click Download**, from the same data the checker uses — so the file and the checker can never get out of sync, and there's no binary file to maintain.

```

├── js/checker.js            Pure checking logic: workbook in → list of results out (no page code)
├── js/check-page.js         Connects check.html's upload button to checker.js and shows results
├── js/lib/xlsx.full.min.js  SheetJS library (local copy, works offline)
├── tests.html               Opens in browser, builds fake right/wrong workbooks, runs checker, shows pass/fail
└── README.md                How to open the app and how files fit together
```

## How the checker works (`js/checker.js`)
For each task cell (E2:E11, H2:H6), in order:
1. **Empty?** → "Cell H2 is empty."
2. **Typed a number instead of a formula?** (`cell.f` missing) → "H2 contains 4,250 but no formula. Use a formula like =SUM(...)."
3. **Formula with no cell references?** (e.g. `=1200+3050`) → "Your formula doesn't refer to the data cells."
4. **Expected function used?** (e.g. H2 should contain `SUM`) → hint if not (soft warning, still passes if value is right — optional rule per task).
5. **Value correct?** Compare `cell.v` to the expected answer (tolerance 0.01) → "Expected 42,350 but got 41,100 — check your range."
6. Also: verify data cells `A2:D11` were not edited (otherwise answers can't be judged); reject non-`.xlsx` files (CSV loses formulas); if a formula has no saved value, say "Open and save the file in Excel, then upload again."

Each result is an object: `{ task, cell, status: "pass"|"fail", message, formula, value, expected }`.
This structured list is what v2's AI tutor will receive.

The results page shows a score ("12 / 15 correct") and a green/red line per cell with the message.

## Build steps
1. Create the folder structure, `README.md`, and download SheetJS into `js/lib/`.
2. Write `js/exercise.js` (data, tasks, expected answers computed from the data).
3. Write `index.html` + `css/style.css` (lesson text: what a formula is, cell ranges, the five functions, worked examples, the task).
4. Write `js/make-practice-file.js` and hook up the Download button; open the file in Excel to confirm it looks right.
5. Write `js/checker.js` (the rules above).
6. Write `check.html` + `js/check-page.js` (upload, run checker, render results).
7. Write `tests.html` with cases: all correct, typed numbers, constant-only formula, wrong range, empty cells, edited data.
8. Manual end-to-end test in real Excel (below).

## Verification
- Open `tests.html` in the browser → every test case shows PASS.
- Real round trip in Excel:
  1. Open `index.html`, download the practice file, solve it correctly in Excel, save, upload on `check.html` → all green.
  2. Replace one formula with its typed number → that cell flagged "no formula".
  3. Change a range (e.g. `=SUM(E2:E10)`) → flagged wrong value.
  4. Upload a `.csv` or random file → friendly error, no crash.

## Assumptions you can change
- Lesson topic (SUM/AVERAGE/MIN/MAX/COUNT + a Revenue column).
- Practice file generated on Download rather than stored as a fixed `.xlsx`.
- No login and no saved progress in v1.
